# Artist Brand Vision Directory

## Instructions

Create a subdirectory for each artist and place their `brand_vision.md` file inside:

```
artists/
├── john_doe/
│   └── brand_vision.md
├── jane_smith/
│   └── brand_vision.md
└── worship_collective/
    └── brand_vision.md
```

## Brand Vision File Format

The `brand_vision.md` file should be in Markdown format and include:

### Required Sections

1. **Artist Name & Identity**
2. **Musical Style & Genre**
3. **Artistic Vision & Mission**
4. **Visual Aesthetic**
5. **Target Audience**
6. **Themes & Messages**
7. **Production Preferences**

## Example: brand_vision.md

```markdown
# Artist Brand Vision

## Artist Name & Identity
**Name**: Sacred Soundscapes
**Tagline**: "Ancient Words, Modern Worship"

## Musical Style & Genre
- Primary: Contemporary Christian Worship
- Secondary: Ambient, Cinematic
- Influences: Hillsong, Bethel Music, Sleeping At Last
- Instrumentation: Piano, strings, ambient pads, subtle electronic elements

## Artistic Vision & Mission
To bring the timeless truths of the Psalms to modern worshippers through contemplative, atmospheric music that creates space for reflection and encounter with God.

## Visual Aesthetic
- Color Palette: Deep blues, warm golds, natural earth tones
- Style: Minimalist, ethereal, nature-inspired
- Imagery: Light, water, mountains, open skies
- Typography: Clean, modern serif fonts

## Target Audience
- Age: 25-45
- Interests: Contemplative spirituality, liturgical worship, deep biblical study
- Setting: Personal devotion, small group worship, meditation

## Themes & Messages
- God's faithfulness and sovereignty
- Hope in suffering
- Wonder and awe at creation
- Intimacy with God
- Justice and righteousness

## Production Preferences
- Sound: Spacious, reverb-heavy, cinematic
- Tempo: Generally slow to mid-tempo (60-90 BPM)
- Dynamics: Build from intimate to powerful
- Vocal Style: Warm, sincere, not overly produced
```

## Notes

- Be as specific as possible - this information drives all asset generation
- Update the brand vision as the artist's style evolves
- Multiple brand visions can exist for different projects/seasons
